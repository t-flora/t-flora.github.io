# t-flora.github.io

Source for [t-flora.github.io](https://t-flora.github.io), Tiago Flora's writing and projects. Built with [Astro](https://astro.build) and deployed to GitHub Pages on every push to `main`.

```bash
pnpm install
pnpm dev     # http://localhost:4321
pnpm build   # type check, build, search index
```

Posts live in `src/content/post/`, the work timeline in `src/content/timeline.yaml`, and projects in `src/content/projects.yaml`. See `CLAUDE.md` for the architecture and `GLOSSARY.md` for the site's vocabulary.

Originally based on [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) by Chris Williams (MIT, see `LICENSE`).
